# Support

This is an AWS sample, maintained on a best-effort basis. It is not covered by
AWS Support plans.

## Getting help

- Check the [README](README.md) for setup, configuration, and usage.
- Search existing [issues](../../issues) to see whether your question has
  already been answered.
- If not, open a new issue using one of the provided templates.

## Reporting security issues

Do not open a public issue for security concerns. See
[CONTRIBUTING](CONTRIBUTING.md#security-issue-notifications) for how to report
them privately.
